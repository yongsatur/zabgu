# Сайт для подачи заявок и статей на конференцию Забайкальского государственного университета

Этот проект был разработан в рамках учебной эксплуатационной практики. Его цель – упростить процесс регистрации участников и сбора научных материалов для конференции. Система интегрирована с Google Drive для хранения данных и файлов с использованием таблиц и облачного хранилища.

[Ссылка на сайт](https://zabgu.ru/php/conference/) для просмотра.

## О проекте

Данный проект был разработан в рамках **учебной эксплуатационной практики** в университете. Он решает проблему сбора, систематизации и хранения заявок на участие в конференции, а также последующей загрузки научных статей.

**Ключевая особенность:** все данные (заявки, статьи, мета-информация) хранятся на Google Drive, что делает систему простой в обслуживании для сотрудников университета.

## Основные возможности

$`\color{yellow}*`$ **Подача заявки на участие** – форма для регистрации участника с указанием всех необходимых данных;<br>
$`\color{yellow}*`$ **Загрузка статей** – форма для прикрепления файлов статей;<br>
$`\color{yellow}*`$ **Хранение данных на Google Drive:** <br>
  $`\color{yellow}*`$ Данные из форм автоматически сохраняются в **Google Таблицы**;<br>
  $`\color{yellow}*`$ Загруженные файлы (статьи) сохраняются в указанную папку на **Google Диске**;<br>
$`\color{yellow}*`$ **Адаптивный интерфейс** – сайт корректно отображается на всех устройствах, от настольных компьютеров до мобильных телефонов.
