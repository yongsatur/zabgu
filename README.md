# Одностраничный веб-сайт для подачи заявок и статей на конференцию Забайкальского государственного университета

Этот проект был разработан в рамках учебной эксплуатационной практики. Его цель — упростить процесс регистрации участников и сбора научных материалов для конференции. Система интегрирована с Google Диском для хранения данных и файлов с использованием таблиц и облачного хранилища.

[Ссылка на сайт]([https://yongsatur.github.io/studio220/](https://zabgu.ru/php/conference/)) для просмотра.

---

## 🎯 О проекте

Данный проект был разработан в рамках **учебной эксплуатационной практики** в университете. Он решает проблему сбора, систематизации и хранения заявок на участие в конференции, а также последующей загрузки научных статей.

**Ключевая особенность:** все данные (заявки, статьи, мета-информация) хранятся на Google Диске, что делает систему простой в обслуживании для сотрудников университета.

## Основные возможности

- **Подача заявки на участие** – форма для регистрации участника с указанием всех необходимых данных;
- **Загрузка статей** – форма для прикрепления файлов статей;
- **Хранение на Google Диске:**
  - Данные из форм автоматически сохраняются в **Google Таблицы**;
  - Загруженные файлы (статьи) сохраняются в указанную папку на **Google Диске**;
- **Адаптивный интерфейс** – сайт корректно отображается на всех устройствах, от настольных компьютеров до мобильных телефонов.
