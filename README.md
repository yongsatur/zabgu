# Сайт для подачи заявок и статей на конференцию

Это заказная разработка для социологического факультета Забайкальского государственного факультета. **Цель сайта** – упростить процесс регистрации участников и сбора научных материалов для конференции. Система интегрирована с Google Диском для хранения данных и файлов с использованием таблиц и облачного хранилища.

## О проекте

Данный проект решает проблему сбора, систематизации и хранения заявок на участие в конференции, а также последующей загрузки научных статей.

**Ключевая особенность:** все данные (заявки, файлы статей) хранятся на Google Диске, что делает систему простой в обслуживании для сотрудников университета.

## Основные возможности

$`\color{yellow}*`$ **Подача заявки на участие** – форма для регистрации участника с указанием всех необходимых данных;<br>
$`\color{yellow}*`$ **Загрузка статей** – форма для прикрепления файлов статей;<br>
$`\color{yellow}*`$ **Хранение данных на Google Диске** – данные из форм автоматически сохраняются в **Google Таблицы**, загруженные файлы (статьи) сохраняются в указанную папку на **Google Диске**;<br>
$`\color{yellow}*`$ **Адаптивный интерфейс** – сайт корректно отображается на всех устройствах, от настольных компьютеров до мобильных телефонов.
